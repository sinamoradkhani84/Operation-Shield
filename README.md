# Operation-Shield

 پروژه‌ای با هدف بهبود دسترسی‌پذیری و پایداری لینک‌های اشتراک طراحی شده است. این پروژه تلاش می‌کند محدودیت‌های اعمال‌شده روی ساب‌دامین‌ها را که ممکن است مانع Import شدن کانفیگ‌ها و به‌روزرسانی اشتراک‌ها شوند، برطرف کند.

هدف اصلی پروژه این است که کاربران بتوانند لینک اشتراک خود را به‌راحتی وارد کلاینت کنند، کانفیگ‌های خود را به‌روزرسانی کنند و بدون دردسر از سرویس استفاده کنند.

### قابلیت‌های اصلی
- بهبود دسترسی به لینک‌های اشتراک
- رفع مشکلات Import کانفیگ‌ها در کلاینت‌های VPN
- بهبود فرایند به‌روزرسانی و دریافت مجدد اشتراک
- افزایش پایداری دسترسی به لینک‌های Subdomain
- ساده‌سازی تجربهٔ کاربری در مدیریت اشتراک‌ها

**هدف نهایی:** فراهم‌کردن تجربه‌ای پایدارتر، ساده‌تر و قابل‌اعتمادتر برای دریافت و به‌روزرسانی کانفیگ‌های VPN.
## راهنمای پیاده‌سازی در Deno

در این بخش نحوهٔ راه‌اندازی Operation-Shield با استفاده از Deno توضیح داده می‌شود.
در قدم اول در deno deploy یک اکانت بسازید برای 5K درخواست HTTP در ماه بدونه نیاز به payment method کار راه میندازه.
https://deno.com/deploy
در  قدم دوم به قسمت App بروید
فلش کنار New Playgroundsvg بزنید و گزینه Hello World Template رو انتخاب کنید.
کدی که داخل sub.ts قرار داده شده است روی کپی کنید و داخل محیط دنو وارد کنید و قبل از Deploy مقادیر خواسته شده داخل کد رو تغییر بدید.
در نهایت یه ساب لینک با فرمنت زیر باید بسازید تا کانفیگ ها از پنل Fetch شوند و پنل بالا بیاد و همچنین ساب ها اپدیت شوند.
